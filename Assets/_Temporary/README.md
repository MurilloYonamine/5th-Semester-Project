# Testing

Arquivos de teste para validar sistemas em runtime/editor sem impactar conteúdo de gameplay.

## Conteúdo
- `Dialogue_Test_Basic.txt`: diálogo simples com 2 speakers.
- `Dialogue_Test_CommentsAndNarration.txt`: comentários e linhas de narração.
- `Dialogue_Test_EscapedQuotes.txt`: validação de aspas escapadas (`\"`).
